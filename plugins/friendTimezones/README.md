# FriendTimezones

Set a friend's timezone from their profile menu, then see their current time next to their name in chat, DMs, and calls.

## Features

- Pick a timezone for any user from the `…` menu on their profile (35 common zones plus UTC).
- Their local time is shown next to their name in messages, DMs and voice calls.
- Timezones are stored locally on your device; nothing is sent anywhere.

## Usage

1. Open a user's profile and click the `…` (more) button.
2. Choose **Timezone** and select their zone, or **Not set** to remove it.

## Settings

None. The plugin is enabled by default once installed.
