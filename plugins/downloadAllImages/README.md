# DownloadAllImages

Adds a download button on image collages that saves every image from that message.

## Features

- A download button appears on messages that show several images as a collage.
- **Desktop app:** pick a folder once and every image in the message is saved there. Duplicate file names are renamed automatically.
- **Web / browser:** each image is downloaded through the browser, one after another.
- Shows how many images were saved, and how many failed if any did.

## Usage

Hover an image collage in any chat and click the download icon.

## Settings

None. The plugin is enabled by default once installed.
